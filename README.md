# Technopolis Website Redesign
A UX/UI redesign project focused on improving navigation, visual hierarchy, and accessibility for the Technopolis website to better serve students, staff, and external partners.

- Role: UX/UI Designer
- Tools: Figma, User Research, Wireframing, Prototyping
  
- Conducted user research and requirements gathering to identify key pain points and usability issues on the current website.
- Designed wireframes and high-fidelity interactive prototypes in Figma, significantly improving navigation and user experience.
- Transformed research insights into intuitive UI components and created a modern layout tailored to user needs.

# Interactive Building Directory Kiosk Redesign
Redesigned the interactive building directory kiosk interface to optimize indoor navigation and allow campus visitors to locate rooms and facilities efficiently.

- Role: UX/UI Designer
- Tools: Figma, Usability Testing, Touch UI Design

- Conducted user research to analyze navigation friction, optimizing map interaction, touch zones, and layout readability for diverse visitors.
- Designed high-fidelity interactive prototypes in Figma, featuring intuitive search, floor-level switching, and accessible touch UI for large displays.
- Improved overall usability by creating clear navigation pathways and user-friendly interface components.

# Mobile App Redesign - Kitooo Store
A collaborative mobile application redesign concept for a favorite local store. The project focuses on modernizing the mobile shopping experience, improving product discoverability, and creating a seamless user journey from product browsing to checkout.

Role: Lead UX/UI Designer
Teamwork: Collaborated with a Frontend Developer to ensure design feasibility and smooth handoff
Tools: Figma, User Flow, Wireframing, High-Fidelity UI, Interactive Prototyping

- Led the complete UX/UI design process in Figma, creating wireframes, user flows, and high-fidelity interactive prototypes.
- Designed intuitive interface components and clear visual hierarchy optimized for mobile shoppers.
- Built clickable interactive prototypes in Figma to demonstrate user interactions and purchasing steps clearly.
- Collaborated closely with the developer team member to align design specs with frontend implementation.
